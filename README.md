# Online-BookStore
The Online Bookstore Website is a responsive web app built with HTML, CSS, and JavaScript, simulating an online book shopping experience. It allows users to browse books with images, add them to a cart, and view dynamic totals. With a clean design and interactive features, it showcases frontend development skills.
